# 📊 Sales Data Analysis Project

> A comprehensive sales data analysis project using Python to explore the Superstore Sales Dataset, identify business trends, and extract actionable insights to support data-driven decision-making.

---

## 🎯 Project Overview

يهدف هذا المشروع إلى تحليل بيانات مبيعات متجر تجاري (Superstore) لفهم الأداء العام للمبيعات، وتحديد الفئات والمنتجات الأكثر تحقيقًا للإيرادات، وتحليل الاختلافات بين المناطق الجغرافية، واكتشاف الأنماط الموسمية للمبيعات.

من خلال استخدام تقنيات تحليل البيانات والاستكشاف البصري (EDA)، يقدم المشروع رؤى تساعد على فهم الأداء التجاري ودعم اتخاذ القرارات المبنية على البيانات.

---

## 🛠️ Technologies & Libraries

تم تنفيذ المشروع باستخدام الأدوات والمكتبات التالية:

- **Python:** لغة البرمجة المستخدمة في تحليل البيانات.
- **Pandas:** لتنظيف البيانات ومعالجتها وتحليلها.
- **NumPy:** للعمليات الحسابية والإحصائية.
- **Matplotlib:** لإنشاء الرسوم البيانية والتصورات البصرية.
- **Jupyter Notebook:** لكتابة الأكواد وتنفيذ التحليلات بشكل تفاعلي.

## 📈 Data Analysis & Visualizations

### 1. Total Sales by Category

تحليل إجمالي المبيعات حسب الفئات المختلفة، مع ملاحظة تصدر فئة **Technology** من حيث إجمالي الإيرادات.

### 2. Total Sales by Region

تحليل توزيع المبيعات جغرافيًا، حيث سجلت منطقة **West** أعلى إجمالي مبيعات، بينما سجلت منطقة **South** أقل إجمالي مبيعات.

### 3. Top 10 Products by Sales

تحديد أكثر 10 منتجات تحقيقًا لإجمالي المبيعات، مع تصدر منتج **Canon imageCLASS 2200 Advanced Copier** القائمة.

### 4. Monthly Sales Trend

تحليل التغيرات الشهرية في المبيعات، مع ملاحظة ارتفاع المبيعات خلال شهري نوفمبر وديسمبر، مما يشير إلى وجود نمط موسمي واضح.

## 💡 Key Business Insights

من خلال تحليل البيانات، تم الوصول إلى مجموعة من الرؤى التجارية المهمة:

1. **Category Performance:** تمثل فئة Technology مصدرًا رئيسيًا لإيرادات المتجر، مما يبرز أهمية متابعة أدائها.

2. **Sales Seasonality:** تظهر زيادة ملحوظة في المبيعات خلال الربع الأخير من العام، وهو ما يمكن الاستفادة منه في التخطيط للمخزون والحملات التسويقية.

3. **Regional Performance:** يوجد تفاوت في إجمالي المبيعات بين المناطق الجغرافية، مما يتيح فرصة لدراسة أسباب اختلاف الأداء وتطوير استراتيجيات مناسبة لكل منطقة.

4. **Product Performance:** يساهم تحديد المنتجات الأعلى مبيعًا في دعم قرارات إدارة المخزون وتخطيط المبيعات.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash

```

### 3. Install Required Libraries

```bash
pip install pandas numpy matplotlib jupyter
```

### 4. Run Jupyter Notebook

```bash
jupyter notebook
```

ثم افتح الملف:

```text

```
